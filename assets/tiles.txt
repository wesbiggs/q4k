# q4k tile set -- the single source of truth for terrain.
#
#   tile <name> <map-char> <screen-code> <flag> <colour>
#   followed by 8 rows of 8 characters: '#' = foreground, '.' = background
#
# The map stores screen codes directly, so drawing the viewport is a copy with
# no translation step. Codes are contiguous from $60 (unused graphics in the
# lowercase charset) so tile properties index as code - TILE_BASE.
#
# flags: pass  walk onto it freely
#        block impassable
#        water impassable on foot; a boat will change that
#        enter stepping on it enters a town/castle/dungeon
#        actor  not terrain at all -- drawn on top of it
