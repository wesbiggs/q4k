# Quest for the King -- town and castle interiors.
#
# Each is exactly one viewport, 21x19, so a town never scrolls: you walk in
# and see the whole place, the way Ultima III's towns felt.
#
#   town <id> <DISPLAY NAME>
#   at <world-x> <world-y>        where it sits on the overworld
#   ent <char> npc <npc-id>       talks, via the dialogue daemon
#   ent <char> shop <weapon|armour|item|bow>
#   ent <char> inn <inn-id> <INN NAME>  ale and a bed; the id keys npcd's hints
#   map                           then 19 rows of 21 characters
#
# Map characters are the tile glyphs from assets/tiles.txt, plus:
#   $  where you arrive (drawn as floor)
#   x  the way out (drawn as a door)
#   1-6  entity slots declared above
